# CoreJ2 v1.0

## Summary

CoreJ2 1.0 runs classic Java ME (J2ME) games natively on iPhone & iPad with an
**embedded OpenJDK Mobile** runtime and a **clean-room MIDP** written from the
public specifications — no FreeJ2ME classes ship in the app. Validated on a
physical iPhone XS Max (iOS 18.7.1).

## Highlights

- Embedded OpenJDK Mobile (Zero) statically linked; `JNI_CreateJavaVM` on device
- Clean-room MIDP 2.0 / CLDC / MMAPI / M3G (pure classpath: 280 classes)
- Pure-Java graphics (no AWT): framebuffer images, PNG/BMP, bitmap fonts, software M3G
- Commercial MIDlets playable: Miami Nights (EN/ES), Gangstar 2, Bounce Tales,
  Real Football 2011, Prince of Persia, Assassin's Creed, Diamond Rush, Asphalt 3D
- On-screen controls (D-pad, soft keys, keypad, touch), settings, vibration
- Native audio (MIDI/WAV), per-game RMS savedata, in-process game switching
- Device profiles 96×65 – 480×800, auto-detected from the JAR

## Known issues

- Asphalt 3: Street Rules 3D (M3G): texture rendering still being polished
- Diamond Rush: freeze after the first touch (fix in progress)
